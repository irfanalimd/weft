# Weft — Architecture & Contracts

This file is the **source of truth for interfaces between components**. Several people/agents
work in parallel; the contracts below are what lets them do that safely.

**Rule:** Contract signatures marked 🔒 are frozen. You may *add* methods/fields freely. If you
must change a frozen signature, update this file in the same change and add an entry to the
[Contract change log](#contract-change-log) at the bottom.

## 1. `weft-core` — the CRDT 🔒

### Model

- `ClientId = u64` (random per replica/session, generated by the caller; the server uses its own id).
- Every **operation** (insert run *or* delete run) has an `Id { client, clock }`. Clocks per client
  are contiguous starting at 0; a run of length `n` consumes clocks `clock..clock+n`.
  - Insert run: `n` = UTF-16 length of inserted text (one clock per UTF-16 code unit).
  - Delete run: `n` = number of target units deleted (one clock per deleted unit).
- **StateVector**: `client → next expected clock`. Because deletes are ops with IDs too, a state
  vector fully identifies a version. That is the basis for delta sync **and** time travel.
- **Algorithm**: a list CRDT with left/right origins (Fugue / YATA family). Fugue's
  non-interleaving is preferred. Items are run-length encoded. Deleted items stay as tombstones.
- **Positions are UTF-16 code units** (to match JS strings / CodeMirror). Never split a surrogate
  pair: callers must pass valid boundaries; core may debug-assert.
- **Causality**: an update whose dependencies (origins, delete targets, earlier clocks of the same
  client) aren't present yet is buffered in a pending queue and integrated when they arrive.
  `apply_update` is **idempotent and commutative**.
- **Binary encoding**: a compact custom format (LEB128 varints, client-table, RLE). Must start with a
  version byte. No serde in core.

### Public API (Rust)

```rust
pub type ClientId = u64;

#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash, PartialOrd, Ord)]
pub struct Id { pub client: ClientId, pub clock: u64 }

#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub struct StateVector(/* BTreeMap<ClientId, u64> */);
impl StateVector {
    pub fn get(&self, client: ClientId) -> u64;
    pub fn contains(&self, id: Id) -> bool;
    pub fn encode(&self) -> Vec<u8>;
    pub fn decode(bytes: &[u8]) -> Result<Self, DecodeError>;
    pub fn iter(&self) -> impl Iterator<Item = (ClientId, u64)> + '_;
}

/// An opaque, self-contained, encoded batch of ops. Cheap to clone/forward.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Update(pub Vec<u8>);
impl Update {
    pub fn is_empty(&self) -> bool;          // contains no ops
    pub fn merge(updates: &[Update]) -> Result<Update, DecodeError>; // compaction w/o a Doc
}

/// A change to apply to a view (e.g. CodeMirror), in UTF-16 positions, in order.
#[derive(Clone, Debug, PartialEq, Eq)]
pub enum Change { Insert { pos: usize, text: String }, Delete { pos: usize, len: usize } }

/// A stable position that survives concurrent edits (for cursors/selections).
#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
pub enum Anchor { Start, End, After(Id) }  // After(id): just after the unit with that Id
impl Anchor { pub fn encode(&self) -> Vec<u8>; pub fn decode(b: &[u8]) -> Result<Self, DecodeError>; }

pub struct Doc { /* ... */ }
impl Doc {
    pub fn new(client: ClientId) -> Self;
    pub fn client_id(&self) -> ClientId;
    pub fn text(&self) -> String;
    pub fn len_utf16(&self) -> usize;

    // Local edits. Return the Update to broadcast (already applied locally).
    pub fn insert(&mut self, pos: usize, text: &str) -> Update;
    pub fn delete(&mut self, pos: usize, len: usize) -> Update;

    // Sync.
    pub fn state_vector(&self) -> StateVector;
    pub fn encode_diff(&self, since: &StateVector) -> Update; // all ops not in `since`
    pub fn encode_full(&self) -> Update;                       // == encode_diff(&Default)
    pub fn apply_update(&mut self, update: &Update) -> Result<Vec<Change>, DecodeError>;
    pub fn has_pending(&self) -> bool;                         // buffered ops awaiting deps
    // The pending queue is capped at MAX_PENDING_UNITS (100k: 1 per run + 1 per char/delete
    // target) or MAX_PENDING_BYTES (8 MiB est.); past that apply_update returns Err.

    // Cursors.
    pub fn anchor_at(&self, pos: usize) -> Anchor;             // anchor sticking to the left char
    pub fn resolve_anchor(&self, a: &Anchor) -> Option<usize>; // None if unknown id

    // History / time travel. Ops are numbered in *local integration order* (causal order).
    pub fn op_count(&self) -> usize;                           // number of op runs integrated
    pub fn version_at(&self, step: usize) -> StateVector;      // version after first `step` runs
    pub fn text_at(&self, version: &StateVector) -> String;
}

#[derive(Debug, thiserror-like)] pub struct DecodeError { /* message */ }
```

Also in scope for core (additive): `UndoManager` (undo/redo of *local* ops only, CRDT-aware: undo an
insert = delete those items; undo a delete = re-insert the text as new items), and benchmarks.

### Invariants that must be tested

- **Convergence**: for random concurrent edits on N replicas, delivering all updates in any order
  (with duplicates) gives identical `text()` and `state_vector()` everywhere.
- **Intention**: a local insert at `pos` appears at `pos` in the local text; `Change`s returned by
  `apply_update` transform the old text to the new text exactly.
- **Diff correctness**: `b.apply_update(a.encode_diff(&b.state_vector()))` gives the same result as
  applying `a.encode_full()`.
- **Time travel**: `text_at(version_at(op_count())) == text()`, `text_at(&StateVector::default()) == ""`.
- **Merge**: applying `Update::merge(&[u1,u2,...])` == applying each individually.

## 2. `weft-sync` — wire protocol + sans-IO sync 🔒

Messages are `serde` + `postcard` encoded, one message per WebSocket binary frame.

```rust
pub const PROTOCOL_VERSION: u16 = 1;

#[derive(Serialize, Deserialize, Clone, Debug, PartialEq)]
pub enum Message {
    /// C→S, first frame. `state_vector` = encoded weft_core::StateVector.
    Hello { protocol: u16, doc_id: String, client_id: u64, state_vector: Vec<u8> },
    /// S→C reply to Hello: everything the client lacks + the server's version.
    SyncStep { update: Vec<u8>, state_vector: Vec<u8> },
    /// Either direction: incremental ops (an encoded weft_core::Update).
    Update { update: Vec<u8> },
    /// Either direction: ephemeral presence. `payload` = UTF-8 JSON (see Awareness below).
    Awareness { client_id: u64, payload: Vec<u8> },
    /// S→C: a peer left (or timed out).
    AwarenessRemove { client_id: u64 },
    /// S→C: fatal error (bad doc id, protocol mismatch). Client should show it, not retry blindly.
    Error { code: u16, message: String },
}
impl Message { pub fn encode(&self) -> Vec<u8>; pub fn decode(b: &[u8]) -> Result<Self, SyncError>; }
```

Handshake (idempotent; safe to repeat on every reconnect):
1. Client connects → sends `Hello{sv_c}`.
2. Server replies `SyncStep{ update: doc.encode_diff(sv_c), state_vector: sv_s }` and sends current
   Awareness of all peers in the room.
3. Client applies the update, then sends `Update{ doc.encode_diff(sv_s) }` (its offline edits), if non-empty.
4. From then on, both sides stream `Update` and `Awareness`.

Sans-IO state machines (no sockets, no tokio; usable from wasm and from tests):

```rust
/// Client side. Owns the Doc.
pub struct ClientSession { /* doc, connection state, ... */ }
impl ClientSession {
    pub fn new(doc_id: String, doc: weft_core::Doc) -> Self;
    pub fn doc(&self) -> &weft_core::Doc;
    pub fn on_connected(&mut self) -> Vec<Message>;                 // -> [Hello]
    pub fn on_disconnected(&mut self);
    pub fn on_message(&mut self, msg: Message) -> Result<ClientOutput, SyncError>;
    pub fn insert(&mut self, pos: usize, text: &str) -> Vec<Message>;  // empty if offline
    pub fn delete(&mut self, pos: usize, len: usize) -> Vec<Message>;
    pub fn set_awareness(&mut self, payload: Vec<u8>) -> Vec<Message>;
    pub fn is_synced(&self) -> bool;          // handshake done and no unacknowledged local ops
    pub fn unsynced_op_count(&self) -> usize; // local ops the server hasn't confirmed (shown in the UI)
}
pub struct ClientOutput {
    pub send: Vec<Message>,
    pub changes: Vec<weft_core::Change>,          // apply to the editor
    pub awareness: Vec<(u64, Option<Vec<u8>>)>,  // peer updates; None = removed
}

/// Server side, one per document. Owns the server replica. Connection ids are opaque u64.
pub struct Room { /* doc, peers, awareness cache */ }
impl Room {
    pub fn new(doc_id: String, doc: weft_core::Doc) -> Self;
    pub fn doc(&self) -> &weft_core::Doc;
    pub fn on_join(&mut self, conn: u64);
    pub fn on_leave(&mut self, conn: u64) -> RoomOutput;            // broadcasts AwarenessRemove
    pub fn on_message(&mut self, conn: u64, msg: Message) -> Result<RoomOutput, SyncError>;
}
pub struct RoomOutput {
    pub to: Vec<(u64, Message)>,      // directed sends
    pub persist: Vec<weft_core::Update>, // new, non-duplicate updates to append to storage
}
```

How "unsynced" gets acknowledged: the server echoes nothing back. The client counts a local op as
confirmed when a later `SyncStep` state vector covers it. While live, ops are optimistically treated
as delivered once sent (the WebSocket is ordered and reliable); on reconnect the handshake
re-derives the truth. (Implementers may refine this; keep `unsynced_op_count` meaningful.)

**Network simulator** (in `weft-sync` tests/`sim` module): deterministic seeded RNG; N clients +
1 room; per-link message drop/duplicate/reorder/delay; random disconnects/partitions; random edits.
After healing and quiescing, every replica's text must equal the server's.

### Awareness payload (JSON, UTF-8)

```json
{ "name": "Ada", "color": "#7c5cff", "cursor": { "anchor": "<base64 Anchor>", "head": "<base64 Anchor>" } | null }
```
The TS session layer produces and consumes this; the server treats it as opaque bytes.

## 3. `weft-server`

- `tokio` + `axum` (WebSocket). One `Room` per open doc, behind a per-room task or mutex.
- Routes:
  - `GET /ws/:doc_id`: WebSocket, binary frames of `weft_sync::Message`.
  - `GET /api/docs/:doc_id/export.md`: current text as `text/markdown`.
  - `GET /api/stats`: JSON `{ docs_open, connections, uptime_secs }`.
  - `GET /healthz`: `ok`.
  - Everything else: static files from `web/dist` (SPA fallback to `index.html`).
- `doc_id` must match `^[A-Za-z0-9_-]{1,64}$`.
- **Persistence** (`DocStore`): `data/docs/<doc_id>.log` is an append-only log of records
  `[len: u32 LE][crc32: u32 LE][update bytes]`. On open: replay the log and ignore a torn/corrupt
  tail record. **Compaction**: when the log exceeds N records/bytes, write `encode_full()` to a temp
  file, fsync, and atomically rename over the log. Unload a room after it has been idle for 60 s.
- Config via env/CLI: `WEFT_ADDR` (default `0.0.0.0:7878`), `WEFT_DATA_DIR` (default `./data`),
  `WEFT_STATIC_DIR` (default `./web/dist`).
- Ping/keepalive; per-connection outbound queue with backpressure; malformed frames close the
  connection, not the room.
- **Abuse limits** (`weft_server::Limits`; env vars, all optional). Refusals send an `Error` frame,
  then close with code 1008.

  | Env var | Default | Effect |
  |---|---|---|
  | — (const `MAX_FRAME`) | 1 MiB | max WebSocket message/frame size from clients |
  | `WEFT_LIMIT_CONNS` | 10000 | concurrent WebSockets server-wide (`OVERLOADED`) |
  | `WEFT_LIMIT_CONNS_PER_IP` | 64 | concurrent WebSockets per client IP, IPv6 grouped per /64 (`RATE_LIMITED`) |
  | `WEFT_LIMIT_MSG_RATE` / `WEFT_LIMIT_MSG_BURST` | 300/s, burst 600 | token bucket on incoming messages per connection (`RATE_LIMITED`) |
  | `WEFT_LIMIT_HELLO_SECS` | 10 | close a connection with no valid `Hello` by then (`MALFORMED`) |
  | `WEFT_LIMIT_DOC_BYTES` | 16777216 (16 MiB) | reject `Update`s once the doc's log would exceed this (compacts first to measure the real state) (`TOO_LARGE`) |
  | `WEFT_LIMIT_ROOMS` | 2000 | docs loaded in memory; when full, rooms without connections are unloaded, else new docs are refused (`OVERLOADED`) |
  | `WEFT_ALLOWED_ORIGINS` | empty | comma-separated extra allowed `Origin`s (full origin or bare host). A present `Origin` must match the `Host` header or this list, else HTTP 403; a missing `Origin` (native clients) is allowed |

- **Client IP**: `X-Forwarded-For` (left-most entry) is used only when the TCP peer is loopback
  (Caddy on the same box overwrites the header); otherwise the peer address. `run` serves with
  `into_make_service_with_connect_info::<SocketAddr>()`, which `app()` requires for `/ws`.
- **Presence binding**: a connection's `Awareness` frames must carry the `client_id` of its first
  valid `Hello`; others (and any sent before `Hello`) are dropped silently.
- **Accounts and private notes** (Weft Wall, full contract in `docs/WALL.md`): SQLite at
  `$WEFT_DATA_DIR/weft.db` (modules `db`, `auth`, `api`), note logs in `$WEFT_DATA_DIR/notes/`
  (a second `DocStore`; the room registry is keyed by `RoomKey::{Doc, Note}`, so the namespaces never
  collide). `/ws/n/:id` requires the owner's `weft_session` cookie (401/403/404 before the upgrade);
  revoking a session or disabling a user closes its sockets (close code 4001). All `/api/*` and
  `/ws/n/*` requests pass one middleware: non-GET requests need the WebSocket `Origin` check and
  `Content-Type: application/json` (logout exempt; else 403/415), then the session is looked up
  (sliding 30-day expiry, cookie re-sent when extended, at most daily). Note seeds (`text`, `from_doc`)
  are written as one insert by `SERVER_CLIENT_ID` (`0x5745465453455256`). Title = first non-empty line
  (heading `#`s stripped, 120 chars); preview = the text after it (280 chars); refreshed ≤ every 2 s per
  note and on unload/shutdown. Search: each term becomes a quoted prefix query `"term"*`, ANDed.

  | Env var | Default | Effect |
  |---|---|---|
  | `WEFT_BOOTSTRAP_TOKEN` | unset | enables `POST /api/auth/setup` while no users exist; min 32 chars (shorter refuses to start); unset = setup disabled |
  | `WEFT_ANONYMOUS_DOCS` | `true` | `false` makes `/ws/:id` and `/api/docs/:id/export.md` answer 404 and disables `from_doc` |

## 4. `weft-wasm` 🔒

Built with `wasm-pack build crates/weft-wasm --target web --out-dir ../../web/src/wasm/pkg`.
Exposes one class wrapping `weft_sync::ClientSession` (byte arrays are `Uint8Array`):

```ts
export class WeftClient {
  constructor(docId: string, clientId: bigint);
  static fromState(docId: string, clientId: bigint, state: Uint8Array): WeftClient; // load from IndexedDB
  readonly clientId: bigint;
  text(): string;
  lenUtf16(): number;
  encodeState(): Uint8Array;                 // full Update, for IndexedDB

  // transport
  onConnected(): Uint8Array[];               // frames to send
  onDisconnected(): void;
  onMessage(frame: Uint8Array): ClientOutputJs;
  // local edits (UTF-16 positions) -> frames to send (empty when offline)
  insert(pos: number, text: string): Uint8Array[];
  delete(pos: number, len: number): Uint8Array[];
  setAwareness(json: string): Uint8Array[];

  isSynced(): boolean;
  unsyncedOpCount(): number;

  // cursors
  anchorAt(pos: number): string;             // base64-encoded Anchor
  resolveAnchor(anchor: string): number | undefined;

  // history
  opCount(): number;
  textAtStep(step: number): string;
}
// ClientOutputJs = { send: Uint8Array[], changes: ({insert:{pos,text}}|{delete:{pos,len}})[], awareness: {clientId: bigint, payload: string|null}[] }
```

## 5. Web session layer (`web/src/sync/`) 🔒

`web/src/sync/types.ts` holds the TypeScript contract the UI codes against. The UI (`src/ui`) must
**only** import from `src/sync/index.ts`, never from `src/wasm/pkg` directly.

Responsibilities of `src/sync`: load WASM once; generate/persist a client id; load and save doc state
in IndexedDB (debounced); manage the WebSocket with exponential backoff + jitter and resync on
`online`/`visibilitychange`; provide the CodeMirror collab extension (local transactions → `insert`/
`delete`, remote `changes` → dispatch with an annotation so they aren't echoed; remote cursor and
selection decorations with name labels); and handle awareness/peer tracking.

A **mock** implementation of the same contract (`src/dev/mockSession.ts`, enabled with `?mock`)
lets UI work proceed before the real layer exists.
